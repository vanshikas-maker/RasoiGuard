# 🛡️ RasoiGuard

**RasoiGuard** is a smart kitchen app that tracks inventory, scans receipts, and monitors expenses to help you eliminate food waste completely.

---

## 📱 Features

- **Smart Ingestion:** Receipt and packaging scanning via OCR, along with SMS invoice parsing and WhatsApp bot integration.
- **Traffic Light Expiry Tracker:** Visual status indicators (Safe, Warning, Critical) to prioritize items nearing expiration.
- **Dynamic Analytics:** Real-time metrics for total spend, money saved, and financial loss from waste.
- **Multi-Workspace Support:** Switch effortlessly between **Household** and **Commercial** kitchen modes.
- **Interactive Calendar:** Track daily grocery purchases, consumption patterns, and monthly food waste logs.

---

## 🚀 Getting Started

Follow these steps to set up, build, and run **RasoiGuard** on your local machine or an Android device/emulator.

### Prerequisites

Ensure you have the following installed on your development environment:

- **Android Studio** (Ladybug or newer recommended)
- **JDK 17** or higher
- **Android SDK** (API Level 34 or higher)
- **Git**
